プライバシーポリシー

shorts-uploader（以下「本ツール」）は、運営者が自分の YouTube チャンネルに動画をアップロードするためだけに使う個人用ツールです。

使用する情報

本ツールは、Google アカウントでの許可（OAuth）を通じて YouTube Data API を使用し、次のことだけを行います。

  • 許可されたチャンネルへの動画のアップロード
  • アップロードした動画のタイトル・説明文・公開設定の登録と変更
  • アップロード先のチャンネル名の確認（間違ったチャンネルに上げないため）

情報の保存

許可によって発行されるアクセス用の情報（トークン）は、運営者のパソコンの中にだけ保存されます。外部のサーバーには送信・保存しません。

第三者への提供

取得した情報を第三者に提供・販売することはありません。広告や分析の目的にも使用しません。

Google API サービスのユーザーデータに関するポリシー

本ツールによる Google API から受け取った情報の使用は、限定的使用の要件を含む Google API サービスのユーザーデータに関するポリシーに従います。

許可の取り消し

許可はいつでも Google アカウントの「サードパーティのアクセス」 から取り消せます。
